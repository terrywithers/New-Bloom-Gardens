# Load & Behold Van Men website

One page, no build step. Lives in this repo but is a **separate site** from New Bloom Gardens.

| File | Purpose |
|---|---|
| `index.html` | The whole site: hero, what we shift, how it works, areas, quote form |
| `style.css` | Styling. Fonts Lilita One + Poppins, terracotta `#d45d3e` on cream `#f8f3e7` |
| `quote.js` | Quote form: sends to Netlify Forms, then offers a pre-filled WhatsApp message |
| `img/` | Illustration and social share image, cut from the poster |

## Going live on Netlify (free)
1. app.netlify.com → **Add new site → Import an existing project → GitHub →** `New-Bloom-Gardens`.
2. Set **Base directory** and **Publish directory** to `load-and-behold`. Deploy.
3. **Forms → quote → Form notifications → Email** to get requests by email.
4. **Domain management → Add a domain** once you've bought one (e.g. `loadandbeholdvanmen.co.uk`).
